# Titan-Roadmap

Titan bleibt eine Alpha auf Debian 13 mit signierten A/B-Systemupdates und Rollback. Das aktuelle Installationsimage und die verfügbaren Updates stehen in der [Installation](INSTALL.md).

Als Nächstes zählen belastbare Betriebsnachweise: Updates und Rollback in Proxmox, Dateirechte mit mehreren SMB-Benutzern, länger laufende Docker-Apps, VM-Installation und Wiederherstellung von Sicherungen. Dazu kommen verständliche Statusmeldungen, konsistente Metriken und bedienbare mobile Ansichten.

Eine Beta setzt reproduzierbare Tests der Kernfunktionen und dokumentierte Grenzen voraus. Erfolgreiche Einmaltests reichen dafür nicht aus. Nutzdaten bleiben unabhängig zu sichern.
