Titan 0.1 ist die erste Ausgabe für Intel- und AMD-Homeserver mit UEFI. Das komprimierte Disk-Image wird direkt auf eine SSD oder NVMe geschrieben. Das Schreiben überschreibt alle Daten auf dem gewählten Laufwerk.

- Eigener signierter Updatekanal und lokaler App-Katalog mit FreshRSS.
- Docker-Apps lassen sich als Eigentümer über die Adresse des Titan-Desktops bedienen. Der isolierte Browser wird beim ersten Start von GitHub geladen.
- Import eigenständiger QCOW2-Images für virtuelle Maschinen, darunter das KVM-Abbild von Home Assistant OS. NAS-Ordner können über virtiofs schreibgeschützt oder beschreibbar eingebunden werden.
- USB-Port-Zuordnung und direkte PCI-Zuweisung geeigneter, für VFIO vorbereiteter IOMMU-Gruppen. Gerätekompatibilität und Gasttreiber hängen von der eingesetzten Hardware ab.
- KI-Suche, Texterkennung, Transkription und MCP auf Basis von umbrelOS 2.1. Modelldateien werden bei Bedarf aus ihren Originalquellen bezogen. Für die Gesichtserkennung müssen die Gewichte separat mit entsprechenden Nutzungsrechten bereitgestellt werden.

Für die Installation wird nur das komprimierte Disk-Image benötigt. Die update-Dateien und das Browser-Archiv gehören zur laufenden Installation. Hinweise zur Einrichtung, zu Datenverbindungen und zu den bisher durchgeführten Tests stehen in der README.
