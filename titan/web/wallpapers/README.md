# Original Titan wallpapers

`coast.svg`, `alpine.svg`, and `valley.svg` are original SVG illustrations
authored for Titan's desktop redesign. Their mountain silhouettes, skies,
water, shoreline, gradients, and texture definitions were written directly
for this project. They contain no external images, fonts, linked resources,
or assets from UmbrelOS or TitanOS.

These files follow the license for original Titan material in the repository
root. Visual references informed the product direction, not the asset source.

## Fjord landscape

`fjord.png` is an AI-generated landscape created for Titan on 8 October 2026
with the built-in Imagegen tool. No input/reference image was supplied. The
generated PNG is included unchanged (1672 × 941 pixels); the three original SVG
wallpapers remain selectable. New browser profiles default to Fjord, while an
existing saved background choice is preserved.

This provenance record describes how the asset was created; it does not assert
exclusive rights or replace the third-party and commercial review described in
[LICENSING.md](../../../docs/LICENSING.md).
